🛡️ Envy-Core

La suite de seguridad definitiva para tus variables de entorno en Node.js.

Características Principales

  • ✦
    Validación de Tipos: Asegura que tus puertos sean números, URLs válidas y correos correctos.
  • ✦
    Generación de TypeScript: Crea un archivo env.d.ts para autocompletado en VS Code.
  • ✦
    Inicialización Rápida: Genera un .env.example seguro a partir de tu .env real.
  • ✦
    Detección de Duplicados: Te avisa si declaraste la misma variable dos veces.
  • ✦
    Auditoría de Seguridad (PRO): Detecta contraseñas débiles y credenciales expuestas.
  • ✦
    Bloqueo de Producción (PRO): Evita el arranque si detecta localhost en producción.
  • ✦
    Encriptación AES-256 (PRO): Encripta tu .env con una clave maestra.
  • ✦
    Escáner de Git (PRO): Revisa tu historial de commits en busca de .env filtrados.

// Arquitectura: Node.js + TypeScript + Crypto (AES-256) + Commander.js.
