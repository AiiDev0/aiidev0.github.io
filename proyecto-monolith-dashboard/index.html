📊 Monolith Dashboard

La plataforma web que analiza tu API y genera documentación en segundos.

Características Principales

  • ✦
    Análisis en Tiempo Real: Pega código, sube archivos o conecta con GitHub.
  • ✦
    Editor Monaco: Mismo motor de VS Code para escribir y editar.
  • ✦
    Historial Local: Guarda tus últimos análisis en el navegador.
  • ✦
    Descargas Directas: Obtén Swagger y Tests con un clic.
  • ✦
    Exportación a GitHub: Guarda los resultados como Gists automáticamente.
  • ✦
    100% Web: Sin instalaciones, funciona en el navegador.

// Arquitectura: Next.js + React + Tailwind CSS + TypeScript.
