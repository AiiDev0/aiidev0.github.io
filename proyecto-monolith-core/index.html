🏗️ Monolith-Core

El framework definitivo para documentar, testear y desplegar APIs en Node.js.

Características Principales

  • ✦
    Análisis de Rutas: Escanea código de Express y Fastify.
  • ✦
    Generación de Swagger: Documentación OpenAPI automática.
  • ✦
    Generación de Tests: Pruebas automáticas para cada ruta.
  • ✦
    Servidor Mock: API falsa para el frontend.
  • ✦
    Generación de SDK: Tipos de TypeScript para el frontend.
  • ✦
    Escáner de Seguridad: Detecta vulnerabilidades comunes.
  • ✦
    Generación de Docker: Dockerfile y CI/CD listos.
  • ✦
    Diagramas HTML: Visualización gráfica de tu API.

// Arquitectura: Monorepo + TypeScript + ts-morph + Express + Docker.
