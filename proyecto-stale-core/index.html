🛠️ Stale-Core

El gestor de dependencias definitivo para Node.js. Detecta, analiza y soluciona problemas de deuda técnica.

Características Principales

  • ✦
    Análisis Masivo: Escanea todas tus dependencias en segundos.
  • ✦
    Reportes: Exporta a JSON, Markdown y CSV.
  • ✦
    Árbol Visual: Muestra un árbol de dependencias con colores.
  • ✦
    Licencias: Tabla con la licencia de cada paquete.
  • ✦
    Filtros (Gratis): Filtra por producción o desarrollo.
  • ✦
    Fix Automático (PRO): Reemplaza paquetes obsoletos en tu package.json.
  • ✦
    Deep Scan (PRO): Analiza el árbol completo de dependencias.
  • ✦
    Seguridad (PRO): Escanea vulnerabilidades conocidas.

// Arquitectura: Node.js + TypeScript + Commander.js + Axios.
