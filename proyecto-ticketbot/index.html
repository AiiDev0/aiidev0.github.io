🎫 TicketBot Core

El sistema de tickets definitivo para Discord, escrito en Node.js. Diseñado para comunidades que buscan una gestión seria y automatizada.

Características Principales

  • ✦
    Panel Interactivo: Botones y menús desplegables sin usar comandos de texto.
  • ✦
    Múltiples Categorías: Soporte, Compras y Reportes (contadores independientes).
  • ✦
    Sistema de Prioridades: Tickets clasificados por color (Baja, Media, Alta).
  • ✦
    Transcripts HTML: Generación automática de historial visual al cerrar el ticket.
  • ✦
    Motivos de Cierre: El staff debe elegir por qué se cierra el ticket para tener métricas claras.
  • ✦
    Calificaciones de Staff: Los usuarios puntúan la atención de 1 a 5 estrellas.
  • ✦
    Métricas y Ranking: Comandos /stats y /top para ver el rendimiento del equipo.
  • ✦
    Auto-Cierre: Cierra tickets abandonados por inactividad (configurable).
  • ✦
    Cooldown Anti-Spam: Evita que los usuarios abran múltiples tickets seguidos.
  • ✦
    Búsqueda Avanzada: Encuentra tickets pasados por usuario, tipo o motivo con /buscar.

// Arquitectura: Node.js + Discord.js v14 + MongoDB + Sistema de eventos modular.
